## Differentiation to implement

Unify commercial CRM and property operations around the same contacts, properties and deals. A property should show its leads, visits, offers, documents, owner and rental operations. Daily priorities should explain which action is due and why, using stored data. Automation should record results and permit retry; AI changes should retain the existing proposal/preview/restore workflow.

Order: reliable access and persistence (this delivery); canonical contacts and explicit lead conversion; activity timeline and next actions; matching and property/deal dossier; booking integrity; reliable provider adapters; audited administration and commercial plans. Each stage needs working end-to-end acceptance checks before marking a capability complete.
