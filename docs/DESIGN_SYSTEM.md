# Design system — consolidation plan

## Inventory

- Public tokens: `tailwind.config.ts` and root variables in `src/index.css`, now mainly white/black/red.
- Working CRM tokens: `supabase/functions/_shared/blueprint/look.ts` → `src/components/crm/theme.ts` → `--crm-*`; still green in light/dark mode.
- Additional legacy tokens: `src/design/tokens.ts`, `src/components/landing/palette.ts`, fixed CSS/dashboard colors.
- Reusable components: SHButton, SHSurface, SHStatus, SHSkeleton; RecordDialog, FilterBar, RecordPanel and runtime table/board/cards views.
- Fonts: bundled Inter Variable and Space Grotesk; system serif in public headings. CRM font names should align with the actual bundled Inter family.

## Corporate asset dependency

Existing layered SVG mark is generated by `src/components/brand/Logo.tsx`; favicon is `public/favicon.svg` with different colors. No separate official image supplied by the owner is tracked. Phase 11 already records this absence. The original SVG/PNG corporate resource must be supplied before replacing mark/favicon. Workspace-uploaded `bp.logo` is customer branding, not the corporate source. Keep the existing mark in this delivery; do not approximate the missing artwork.

## Target

Consolidate a single semantic token source for canvas/surface/text/muted/border/brand/focus and success/warning/danger/info. Carry the public white/black/red direction through login, CRM shell, fields, tables, modals and empty/error states; use semantic status colors independently of branding. Preserve light/dark preference with tested contrast in both modes.

Use the existing spacing scale (4/8/12/16/24/32/48) and Inter for dense working screens. Reuse standard buttons, labeled inputs, visible focus, field errors, save/pending/failure feedback and accessible dialogs. Keep destructive actions separate, explicit and permission-aware.

Navigation should evolve into CRM, Properties, Rentals, Operations, Analytics and Administration **only when corresponding screens work**. Leads and Clients need distinct destinations and lifecycle semantics. Preserve existing unknown/custom module navigation under an appropriate group.

Acceptance for the shell delivery: one token change reaches public and internal screens; no hard-coded legacy brand green remains in those migrated surfaces; keyboard and focus tests pass; 390 px/desktop and dark/light screenshots are reviewed; loading/error/empty/denied states remain usable. No visual redesign is claimed in the audit/P0 delivery.
